# @ndop/primitives

Headless, signal-based Angular directives for state, keyboard, focus, ARIA and overlay wiring. No styles.

> Not released yet. This package's API lands in Phase 1 of
> [RFC-0001](../../rfcs/0001-ndop-ui.md).

## Install

```bash
pnpm add @ndop/primitives
```
