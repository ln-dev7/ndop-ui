# Default theme

## 0.2.0

Muted text in light mode is a little darker, `oklch(0.545 0 0)` instead of
shadcn's `oklch(0.556 0 0)`, so it reads at 4.5:1 on the muted background
as well as on the page (ADR-0006, amendment 2). If you changed the value
yourself, `ndop update` keeps your change.
