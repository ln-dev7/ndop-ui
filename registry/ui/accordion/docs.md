An accordion stacks headed sections that each show or hide their content,
such as a list of frequently asked questions. Each heading's button opens
its section; by default one section is open at a time, `multiple` lets
several be, and `collapsible` lets the open one close again. The arrow
keys move between the buttons.

## Do

- Put each trigger in a heading of the level that fits the page.
- Keep the headings short enough to scan.
- Use `collapsible` unless one section must always stay open.

## Don't

- Don't hide content everyone needs; show it.
- Don't use it for a single section; use Collapsible.
