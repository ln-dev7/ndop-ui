A switch turns a setting on or off, taking effect right away, like the
switches in a phone's settings. It's a native button announced as a
switch, with its state as on or off, and binds with `[(checked)]` or any
forms library. The thumb moves to the end side when it's on, so it
mirrors in right-to-left layouts. A small size suits dense lists.

## Do

- Name it with a label that says what it controls, such as "Airplane
  mode".
- Apply the change as soon as it's switched.

## Don't

- Don't use a switch in a form that's only applied when submitted; use a
  Checkbox.
- Don't change the label with the state, such as "On" and "Off".
