An empty state fills the space where content would be when there's none
yet: no projects, no results, no messages. It says what's missing and
what to do about it, with an optional icon or image and actions.

## Do

- Say what would be here, and how to get some: "No projects yet. Create
  one to get started."
- Give it one main action, such as a button that creates the first item.
- Tell search and filter results apart from a truly empty list, and offer
  to clear the filters.

## Don't

- Don't leave a blank area or a table with only headers instead.
- Don't use it for errors; use an alert, which says what went wrong.
